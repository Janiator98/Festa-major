# Ruta Festa Major · Esquerra de l'Eixample

Mapa per al mòbil amb els 66 comerços i centres que es volen visitar per la festa major.

**Enllaç:** https://janiator98.github.io/Festa-major/

## Com obrir-lo

- Obre l'enllaç amb **Chrome o Safari**.
- Si l'obres des de WhatsApp o del correu, tria "Obrir al navegador". Els navegadors interns d'aquestes apps poden donar problemes.
- **Opcional:** al menú del navegador, "Afegeix a la pantalla d'inici" el deixa com una app.
- Cal connexió a internet per carregar el mapa de fons.

## Funcionalitats

| Funció | Com s'utilitza |
|---|---|
| **Punts per prioritat** | 🔴 Alta (9) · 🟠 Mitja (40) · 🟢 Baixa (17) |
| **Fitxa de cada lloc** | Toca un punt i surten el tipus, el nom, l'adreça, la prioritat, el contacte i el sector |
| **Com hi arribo** | Botó dins la fitxa que obre la ruta a peu a Google Maps |
| **Filtre de prioritat** | Toca Alta, Mitja o Baixa per veure només aquell grup; en pots combinar més d'una. *Totes* ho torna a mostrar tot |
| **Contacte** | La fitxa indica si hi ha contacte amb el lloc. El filtre *Amb contacte* (32) / *Sense contacte* (34) es combina amb els altres |
| **Filtre de sector** | 6 zones per proximitat (1–6). Toca un número per fer zoom a la zona. *Tots* ho mostra tot |
| **Ruta proposada** | Dibuixa el recorregut més curt dins de cada sector, amb les parades numerades, la distància i el temps a peu. Es recalcula amb els filtres actius |
| **Marcar com a visitat** | Botó dins la fitxa. El punt queda pàl·lid i a dalt es compten els visitats |
| **On sóc** (⊕) | Botó de baix a la dreta. Mostra la teva ubicació i et segueix. La primera vegada cal donar permís |
| **Veure-ho tot** (⛶) | Botó de sobre: torna a encabir tots els punts visibles |

## Si alguna cosa no funciona

| Problema | Solució |
|---|---|
| Pantalla en blanc | No l'obris des de WhatsApp, el correu o Fitxers: fes servir l'enllaç. Si encara surt en blanc, actualitza el navegador |
| Fons del mapa gris | Revisa la connexió i desactiva el bloquejador d'anuncis o la VPN |
| La ubicació no funciona | Accepta el permís (o activa'l a la configuració del lloc al navegador) i encén la ubicació del mòbil |
| Es veu una versió antiga | Recarrega la pàgina |

## A tenir en compte

- Les marques de **visitat** es guarden només al mòbil de cadascú; no es comparteixen.
- Algunes posicions són **aproximades** (a mitja illa com a molt): AstraZeneca / Edifici Estel, Mare Auxiliadora, Escola Xirinacs i Facultat de Medicina.
- L'**Escola Entença** està situada segons OpenStreetMap, que no coincideix amb l'adreça de l'Excel (Provença 121). Cal confirmar quina és la bona.
- El **Basic Fit** no hi és perquè no tenia adreça.
- Mapa de fons: Esri. Adreces localitzades amb OpenStreetMap.
